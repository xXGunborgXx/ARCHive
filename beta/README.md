# ARCHive Seven-Day Beta

Thank you for testing ARCHive. This package contains a non-production Windows
11 x64 beta for safe file copying, 7z/ZIP creation, and archive extraction.

## Package Contents

1. `ARCHive-Beta-1.2.1-beta4-7day-Setup.exe` - application installer
2. `README.md` - this quick-start guide
3. `INSTRUCTIONS_AND_DISCLOSURES.txt` - plain-text instructions and full local
   record disclosure
4. `ARCHive_Beta_Test_Questionnaire.docx` - editable feedback form

## Seven-Day Limit

The trial begins on the first launch and lasts seven consecutive days.
ARCHive checks the trial at startup only. It will not stop an operation that is
already running when the expiry time is reached.

The local trial record survives normal uninstalling and reinstalling. Moving
the Windows clock backwards by more than the allowed correction tolerance can
lock the beta.

## Install

1. Keep another verified copy of every important test file.
2. Run the installer as a normal Windows user.
3. Read the trial, privacy, and logging disclosure.
4. Complete installation and launch ARCHive.
5. Note the expiry date shown on first launch.

The installer is not code-signed. Windows may display an Unknown Publisher or
SmartScreen warning. Do not bypass organizational security policy; ask your
administrator if installation is blocked.

## Suggested Tests

- Copy one file, one folder, and mixed files/folders.
- Copy between HDD, SSD, removable, network, or VM storage where available.
- Try Pause/Resume on a folder containing several files.
- Cancel a copy and confirm no incomplete dated output is presented as
  successful.
- Create both 7z and ZIP archives.
- Extract both archive types and open the completed destination.
- Try large files and many small files.
- Confirm progress, percentage, speed, and waiting-for-storage messages remain
  understandable.
- Check the fixed-size interface and installer at your normal display scaling.
- Right-click context menu: Copy with ARCHive, Archive with ARCHive,
  Extract with ARCHive for .7z and .zip files.

Use disposable test data whenever possible. This beta must not be the only
copy of important files.
