# Security Policy

## Supported Version

The current seven-day beta is supported for security and data-integrity
reports. It is not a production backup product.

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability that could expose data,
allow unsafe archive extraction, bypass destination safety checks, or damage
file integrity.

Email `GunborgServers@gmail.com` with:

- the affected ARCHive version;
- a concise description and reproduction steps;
- expected and observed behavior;
- whether source or destination data may be affected; and
- a minimal, sanitized proof of concept if available.

Do not attach private files or unreviewed diagnostic JSON. Diagnostic records
can contain complete local file and folder paths.

You should receive an acknowledgement within seven days. Details may be
published after a fix or mitigation is available.
